# Reviewctl Quick Reference for Agents

**TL;DR**: Use this exact flow when running reviewctl.

---

## Quick Start

```bash
# Set CLI path (use absolute path ALWAYS)
REVIEW_CLI="/Users/felipe_gonzalez/Developer/branch-review/mini-services/reviewctl/src/index.ts"

# Standard workflow
bun $REVIEW_CLI init --create
bun $REVIEW_CLI explore context
bun $REVIEW_CLI explore diff
bun $REVIEW_CLI plan
bun $REVIEW_CLI run
# (execute agents and ingest reports...)
bun $REVIEW_CLI verdict --allow-incomplete
```

---

## Critical Rules

1. **ALWAYS use absolute path**:
   - ❌ `mini-services/reviewctl/src/index.ts` (fails in other repos)
   - ✅ `/Users/felipe_gonzalez/Developer/branch-review/mini-services/reviewctl/src/index.ts`

2. **NEVER use standalone build**:
   - ❌ `.next/standalone/mini-services/reviewctl/...`
   - ✅ Use the source CLI directly

3. **When plan is AMBIGUOUS/MISSING**:
   - `plan` will show warning
   - `plan` will generate `plan.md` with status `AUTOGENERATED`
   - `run` will work normally (FIXED as of 2026-03-01)

---

## Plan Status Guide

| Status        | Action Required? | Notes                                    |
| ------------- | ---------------- | ---------------------------------------- |
| FOUND         | No               | Uses explicit plan from docs/plans/      |
| AUTOGENERATED | No               | Plan-less generated from stack detection |
| MISSING       | No               | Same as AUTOGENERATED                    |
| AMBIGUOUS     | No               | Same as AUTOGENERATED                    |

**ALL** of the above allow `run` to proceed after the AUTOGENERATED fix.

---

## Troubleshooting

| Error                                    | Cause                                   | Fix                  |
| ---------------------------------------- | --------------------------------------- | -------------------- |
| "Module not found"                       | Relative path in wrong repo             | Use absolute path    |
| "✗ failed (0s) unknown"                  | Old reviewctl without AUTOGENERATED fix | Update branch-review |
| "Precondition failures: Plan is MISSING" | plan.md does not exist                  | Run `plan` first     |

## Commands Cheat Sheet

```bash
# Status
bun $REVIEW_CLI status --last

# Explore
bun $REVIEW_CLI explore context
bun $REVIEW_CLI explore diff

# Plan
bun $REVIEW_CLI plan
bun $REVIEW_CLI plan --plan-path docs/my-plan.md

# Run
bun $REVIEW_CLI run
bun $REVIEW_CLI run --no-plan
bun $REVIEW_CLI run --allow-drift  # debug only

# Ingest
bun $REVIEW_CLI ingest --agent code-reviewer --input report.md
bun $REVIEW_CLI ingest --static biome --input /tmp/biome.md

# Verdict
bun $REVIEW_CLI verdict
bun $REVIEW_CLI verdict --allow-incomplete

# Cleanup
bun $REVIEW_CLI cleanup
bun $REVIEW_CLI cleanup --all
```

## Common Workflows

### Workflow 1: Standard Review

```bash
bun $REVIEW_CLI init --create
bun $REVIEW_CLI explore context
bun $REVIEW_CLI explore diff
bun $REVIEW_CLI plan
bun $REVIEW_CLI run
# (run agents, ingest reports)
bun $REVIEW_CLI verdict
```

### Workflow 2: Explicit Plan

```bash
bun $REVIEW_CLI init --create
bun $REVIEW_CLI explore context
bun $REVIEW_CLI explore diff
bun $REVIEW_CLI plan --plan-path docs/plans/my-plan.md
bun $REVIEW_CLI run
# (run agents, ingest reports)
bun $REVIEW_CLI verdict
```

### Workflow 3: Force Plan-less

```bash
bun $REVIEW_CLI init --create
bun $REVIEW_CLI run --no-plan
# (run agents, ingest reports)
bun $REVIEW_CLI verdict
```

## Verification Steps

After running `plan`:

```bash
# Verify plan.md exists
ls _ctx/review_runs/run_*/plan.md

# Verify plan_status
cat _ctx/review_runs/run_*/run.json | jq .plan_status
# Expected: "FOUND" or "AUTOGENERATED"
```

After running `run`:

```bash
# Verify requests generated
ls _ctx/review_runs/run_*/reports/REQUEST_*.md

# Verify run completed
bun $REVIEW_CLI status --last
# Should show: Status: pending_ingest
```
